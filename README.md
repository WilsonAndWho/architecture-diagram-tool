# 架构图绘制工具

一个无需安装、无需构建的浏览器端架构图编辑工具。项目以单文件 HTML 的形式运行，支持在本地创建和维护架构图，并将图纸导出为 SVG/PNG，或将存档保存为 XLSX 文件。

## 功能

- 创建、编辑和删除节点、区域框、提示框、文本框及连线
- 拖拽、缩放、框选、多选、复制、镜像复制、格式刷
- 节点和连线属性编辑，包括颜色、字体、边框、箭头和布局等
- 按节点、连线、区域框等属性搜索和筛选
- 撤销 / 重做
- 内置图标库和模板库
- 从本地文件夹读取和保存 XLSX 架构图存档
- 自动保存、手动保存和历史版本管理
- 导出 SVG 矢量图和 PNG 位图
- 内置新手教程

## 快速开始

### 直接运行

1. 下载或克隆本项目。
2. 双击打开 `架构图绘制工具V1.5.1(20260928)合并版.html`。
3. 按页面提示选择一个用于存放 XLSX 存档的文件夹，并授予浏览器读写权限。

合并版不需要安装 Node.js、npm 或其他依赖。推荐使用最新版 Chrome 或 Edge，以获得本地文件夹读写 API 的完整支持。

### 使用本地静态服务器（可选）

如果浏览器限制了直接打开本地 HTML 文件，可以在项目目录运行：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000/>。

## 基本操作

1. 点击“+节点”或“+区域”添加元素。
2. 在画布中拖动元素调整位置，使用右侧属性面板修改样式和业务属性。
3. 使用连线工具连接元素，并在属性面板中设置方向、线型和标签。
4. 使用“更换存档”新建或打开 XLSX 存档。
5. 使用“手动保存”或自动保存功能写入当前存档。
6. 使用“导出 SVG”或“导出 PNG”生成图片文件。

## GitHub Pages 部署

本项目是纯静态文件，可以直接使用 GitHub Pages 发布：

1. 将项目推送到 GitHub 仓库。
2. 打开仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 选择默认分支和 `/ (root)` 目录并保存。
5. 等待 GitHub Actions 完成部署后，通过 Pages 地址访问工具。

建议将合并版 HTML 重命名为 `index.html`，这样 Pages 地址打开后会直接进入工具：

```powershell
Rename-Item '架构图绘制工具V1.5.1(20260928)合并版.html' index.html
```

如果保留原文件名，也可以通过对应的 HTML 路径访问。

## 浏览器兼容性

- 推荐：最新版 Google Chrome、Microsoft Edge
- 需要支持：File System Access API、IndexedDB、Canvas、SVG
- Safari、Firefox 可能无法完整支持本地文件夹读写和 XLSX 存档流程

## 隐私说明

项目默认在浏览器本地运行。架构图数据和 XLSX 存档写入用户选择的本地文件夹，不会由本项目自动上传到第三方服务。发布到公开 GitHub 仓库后，仓库中的 HTML、图标数据和内置模板将对所有人可见。
